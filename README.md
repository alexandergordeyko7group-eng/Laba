Лабораторная работа №2: создание потоков + дополнительное задание DLL

Состав:
main.cpp — основной поток, потоки min_max и average, загрузка DLL.
array_helper.h — тип указателя на функцию и объявление экспорта.
array_helper.cpp — функция замены минимального и максимального элементов.
CMakeLists.txt — сборка программы и DLL.

Требуется Windows, CMake и компилятор C++.
Для Visual Studio установите компонент «Разработка классических приложений на C++».

В терминале в папке проекта:
cmake -S . -B build
cmake --build build --config Debug

Запуск в PowerShell:
cd build\bin
.\Lab2.exe

Запуск в cmd:
cd build\bin
Lab2.exe

Если используется MinGW, из терминала с g++ и mingw32-make в PATH:
cmake -S . -B build-mingw -G "MinGW Makefiles"
cmake --build build-mingw
cd build-mingw\bin
.\Lab2.exe

Lab2.exe и array_helper.dll должны находиться вместе.
Запускайте из папки bin. Main загружает DLL по имени.
При использовании MinGW необходимые DLL самого компилятора должны быть в PATH.

Пример ввода:
5
1 4 8 2 5

Программа выводит минимум 1, максимум 8 и среднее 4.
Результат: 4 4 4 2 5.
Порядок строк от потоков min_max и average может меняться.

Как работает:
1. Основной поток читает целочисленный массив.
2. CreateThread запускает два рабочих потока.
3. min_max находит индексы минимума и максимума.
   После каждого сравнения вызывается Sleep(7), то есть два раза на итерацию.
4. average суммирует элементы, после каждого сложения вызывает Sleep(12).
   Среднее вычисляется как double.
5. Основной поток ждёт завершения обоих через WaitForSingleObject с INFINITE.
6. Загружает DLL через LoadLibraryA, получает функцию через GetProcAddress.
7. Вызывает замену и сразу выгружает DLL через FreeLibrary.
8. Выводит изменённый массив.

Уточнения к условию:
Массив целочисленный, поэтому при записи дробного среднего дробная часть
отбрасывается к нулю: 3.7 превращается в 3, а -3.7 в -3.
Заменяется первое вхождение минимума и первое вхождение максимума.
Если все числа одинаковые, индексы совпадают и результат не меняется.
Рабочие потоки только читают массив; каждый записывает свои отдельные поля.
Основной поток меняет массив только после окончания обоих рабочих потоков.
Интерфейс на английском, чтобы избежать проблем с кодировкой консоли Windows.
